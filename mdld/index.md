# Knowledge graphs in plain Markdown with semantic annotations

Read more at https://mdld.js.org/README.md (follow relative links to find examples and RDF ontologies to get grounded)

This allows us to create and maintain meaningful knowledge that would not need to be derived again and again in plain text, but interconnected into a web of facts and relations between entities. This allows us to store data while also keeping narrative and coherent nature of the informational context. 

We have a [transformed official NASA Venus Transits Catalog](./venus-transit-catalog.mdld.md) and also [Octaeteris planetary numbers collection](./Octaeteris.mdld.md) in the making. There would be more!

Also we provide a complementary JS file that parses the knowledge graph and provides useful programmatic surface extracted from this particular graph - as used in our apps and infinitely reusable further.
